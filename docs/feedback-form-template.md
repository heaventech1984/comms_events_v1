# Member feedback (Google Form)

Short, members first. Plain ASCII punctuation only.

Run `scripts/build-feedback-form.gs` in Apps Script against the form ID, or copy below by hand.

---

## Settings

| Setting | Value |
| --- | --- |
| Title | **Member feedback** |
| Collect email | Off |
| Limit to 1 response | Off |
| Allow response editing | On |
| Progress bar | On |

**Description:**

> For members (and anyone helping). Tell us what is broken, confusing, or missing.  
> Do not write passwords or other people's private details.  
> One clear note is enough. Thank you.

---

## Questions

### About you
1. **Who are you?** (dropdown, required) - Member / Cell leader / Helper / volunteer / Admin / Guest / Prefer not to say  
2. **If we share this in the group chat, how may we name you?** (dropdown, required) - Use my first name / Say my role only / Keep me anonymous  
3. **First name** (short, optional)  
4. **Which app?** (dropdown, required) - Gather / Other / Not sure  

### Your note
5. **What is this?** (choice, required) - Something broken / Confusing / Something missing / Idea / Praise  
6. **How urgent for you?** (choice, required) - Blocks me now / Annoying / Nice to have / Just noticing  
7. **Which part of the app?** (dropdown, required) - member surfaces first  
8. **What happened (or what do you want)?** (paragraph, required)  
9. **Could this confuse or show private member data?** (choice, required) - No / Maybe / Yes  

### Sharing
10. **OK to share this note in the usual group chat?** (choice, required) - Yes / Yes but keep my name off it / No - private to An / Guillaume  
11. **Contact (optional)** (short) - only if they want a reply  

**Confirmation:** Thank you - your note is in. We will never ask for a password through this form.
